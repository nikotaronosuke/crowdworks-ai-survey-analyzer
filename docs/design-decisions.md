# 設計・分析判断

[English](design-decisions.en.md) | 日本語

この文書は2026-09-20に、公開記事と既存の仕様書をもとに後から整理したものです。同時進行で書かれた判断ログではありません。各項目は、リンク先の公開資料で確認できる内容だけに絞っています。

## 1. 分析単位を「人」ではなく「1件の仕事」にした

分析対象は99件ですが、回答者は92人で、7人が別の仕事について2件ずつ回答していました。

そのため記事では「99人」ではなく**92人から寄せられた99件の仕事**として扱い、全99件を独立した人の標本とみなす検定を主張の根拠には使っていません。

**Evidence:** [公開記事](https://poimono.jp/articles/generative-ai-work-survey/)

## 2. 整合しない1件は推測で修正せず、分析から除外した

収集した100件のうち1件は、仕事の時期と利用したAIの公開時期を両立できませんでした。

日付やAI名を「たぶんこうだろう」と補正せず、記事の分析対象から除外しました。一方、ツール側では除外と削除を分け、監査用の `responses.csv` には全行を残して `included=true/false` を出力します。

**Evidence:** [公開記事](https://poimono.jp/articles/generative-ai-work-survey/) / [responses.csv contract](SPEC.md#srcexportcsv)

## 3. 自動パーサーは曖昧な作業時間を推測しない

作業時間は自由記述です。ツールの自動パーサーは、`3時間` のように一意に読める形だけを派生値へ変換します。

`8` のような単位なしの値、`3週間` のように日数へ一意に落とせない記述、複数の時間が別の意味で並ぶ文章は **解析不能** として残します。0や未回答には変換せず、原文も変更しません。

公開記事では別途、単位なし4件を「時間」として解釈したことを明記しています。これは記事作成時の明示的な分析判断であり、ツールの自動パーサーが推測しているわけではありません。

**Evidence:** [work-time parser contract](SPEC.md#srccoreworktimets--実際の作業時間の派生値) / [公開記事](https://poimono.jp/articles/generative-ai-work-survey/)

## 4. 計算できても、平均時給や因果関係を主張の中心にしなかった

報酬は帯回答が多く、作業時間は自由記述で、210時間という大きな値も1件ありました。

そのため記事では平均時給を主指標にせず、報酬帯・作業時間の分布・中央値を中心にしました。

また、AI利用割合が高いグループほど「AIがなければ受けていなかった」割合が高いというクロス集計も、**今回の99件で見えた関連**として記述し、因果関係とはしていません。99件は92人からの回答なので、全件を独立標本とみなす検定も主張の根拠には使っていません。

**Evidence:** [公開記事](https://poimono.jp/articles/generative-ai-work-survey/)
