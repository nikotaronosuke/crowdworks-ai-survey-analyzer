# Owner Decision Log

日本語 | [English](OWNER_DECISIONS.en.md)

このツールでは、実装判断より「データから何を言ってよいか」を決めた場面の方が重要でした。残すのは4件です。

## 1. 「99人」ではなく「92人から寄せられた99件の仕事」とした

7人が別の仕事について2件ずつ回答していたため、分析対象99件は92人から寄せられたものでした。

分析単位を「人」ではなく「1件の仕事」とし、全99件を独立標本とみなす検定も主張の根拠には使いませんでした。

**Evidence:** [公開記事](https://poimono.jp/articles/generative-ai-work-survey/)

## 2. 整合しない1件を推測で直さず除外した

100件のうち1件は、仕事の時期と利用したAIの公開時期を両立できませんでした。

日付やAI名を「たぶんこうだろう」と補正せず、分析対象から除外しました。

ツール側でも除外は削除とは別で、`responses.csv` には `included=false` として元回答を残します。

**Evidence:** [公開記事](https://poimono.jp/articles/generative-ai-work-survey/) / [responses.csv contract](SPEC.md#srcexportcsv)

## 3. 作業時間を無理に数値化せず「解析不能」を残した

自由記述には `3時間` のように読めるものと、`8`、`3週間`、`応募に1分、作業に3分` のように一意に解釈できないものが混在しました。

最初の数字を拾わず、確実に読めないものは **解析不能** として集計。0にも未回答にも変換せず、原文はそのまま残します。

**Evidence:** [worktime parser contract](SPEC.md#srccoreworktimets--実際の作業時間の派生値)

## 4. 平均時給と因果関係を記事の主張にしなかった

報酬と時間から平均時給は計算できますが、報酬が帯回答、時間が自由記述で、210時間という大きな値もありました。

そのため平均時給を主指標にせず、報酬帯・時間分布・中央値を中心にしました。

また「AI利用割合が高いほど、AIなしでは受けなかった割合が高い」というクロス集計も、**今回の99件で見えた関連**までに留め、因果関係とは書いていません。

**Evidence:** [公開記事](https://poimono.jp/articles/generative-ai-work-survey/)
